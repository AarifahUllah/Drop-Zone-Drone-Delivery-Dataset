Overview

OpenDV collects crowdsourced drone videos, flight logs and descriptions, and releases them to the public for building perception and reasoning AI models for drone applications.

Hundreds

of drone videos with a downward-facing camera

Diverse

locations, seasons, times of day, lighting and weather

3 files

per sample: video, flight log and a text description

Applications

  • Package delivery
  • Search and rescue
  • First response
